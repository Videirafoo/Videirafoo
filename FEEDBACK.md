# Feedback — GitHub Student Dashboard

O Dashboard já está público e esta etapa existe para transformar uso real em melhorias verificáveis.

## Teste público

https://github-student-dashboard-videirafoo.onrender.com

## Enviar feedback

Use o formulário estruturado:

https://github.com/Videirafoo/Videirafoo/issues/new?template=dashboard-feedback.yml

O formulário pergunta:

- seu nível atual;
- quais recursos você testou;
- o que foi mais útil;
- o que ficou confuso;
- qual melhoria deveria vir primeiro.

## Como o feedback será priorizado

Ordem padrão:

1. problemas que impedem uma análise;
2. resultados incorretos ou sem evidência;
3. pontos que confundem iniciantes;
4. acessibilidade e clareza;
5. melhorias de fluxo;
6. recursos novos.

## Segurança

Não publique:

- tokens;
- chaves de API;
- senhas;
- cookies de sessão;
- dados privados.

Feedback deve ajudar a reproduzir um problema sem expor segredos.
