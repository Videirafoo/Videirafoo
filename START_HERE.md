# Comece por Aqui

Esta trilha organiza os repositórios públicos do `Videirafoo` em uma sequência recomendada para quem está começando em programação com Python.

## 1. Fundamentos

Comece por [Lista-01-segundo-periodo](https://github.com/Videirafoo/Lista-01-segundo-periodo).

Você vai praticar entrada e saída, variáveis, operações, condicionais, laços, listas e funções.

## 2. Listas e manipulação de dados

Depois siga para [Lista-02-segundo-periodo](https://github.com/Videirafoo/Lista-02-segundo-periodo).

O foco passa a ser percorrer, buscar, alterar e organizar dados em listas.

## 3. Algoritmos de busca

Avance para [Lista-03-segundo-periodo](https://github.com/Videirafoo/Lista-03-segundo-periodo).

Compare busca sequencial e busca binária e observe o custo de cada estratégia.

## 4. Recursividade

Estude [lista-04-segundo-periodo](https://github.com/Videirafoo/lista-04-segundo-periodo).

Aprenda a identificar caso base, passo recursivo, redução do problema e retorno das chamadas.

## 5. Revisão

Use [lista-05-revisao-segundo-periodo](https://github.com/Videirafoo/lista-05-revisao-segundo-periodo) para consolidar os fundamentos.

Não apenas releia: tente resolver novamente sem consultar a solução.

## 6. Primeiro pequeno sistema

Aplique os conceitos no [jogo_primeiro_periodo](https://github.com/Videirafoo/jogo_primeiro_periodo).

Aqui os fundamentos deixam de aparecer isolados e passam a trabalhar juntos em um programa completo.

## Método recomendado

Para cada etapa:

1. leia o problema;
2. tente resolver sozinho;
3. execute e teste;
4. compare com a solução;
5. altere o código;
6. explique com suas palavras;
7. faça um pequeno desafio extra.
