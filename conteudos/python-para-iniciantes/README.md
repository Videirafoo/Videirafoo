# Python para Iniciantes

Trilha prática do GitHub `Videirafoo` para quem está começando do zero.

## Como estudar

Siga os módulos na ordem. Em cada um:

1. leia a explicação;
2. digite o código com as próprias mãos;
3. execute e altere o exemplo;
4. tente o exercício sem olhar a solução;
5. compare sua resposta;
6. explique em voz alta o que o código faz;
7. avance somente quando conseguir modificar o exemplo sozinho.

## Regra da trilha

O objetivo não é decorar sintaxe. É aprender a **ler, escrever, testar, explicar e melhorar código**.

## Nível esperado ao concluir

Ao final, a pessoa deverá conseguir construir um pequeno sistema em Python com menu, funções, validação, listas/dicionários, persistência em JSON, tratamento de erros, documentação e testes básicos.
