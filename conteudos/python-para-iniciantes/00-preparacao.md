# 00 — Preparação

## O que você vai aprender

- o que é um arquivo Python;
- como verificar se o Python está instalado;
- como executar um programa pelo terminal;
- como usar `print()`;
- diferença entre escrever código e executar código.

## Primeiro teste

No terminal:

```bash
python --version
```

Se o comando não funcionar, tente:

```bash
python3 --version
```

## Primeiro programa

Crie `ola.py`:

```python
print("Olá, Python!")
```

Execute:

```bash
python ola.py
```

## Entenda o que aconteceu

`print()` mostra uma informação na tela. O texto entre aspas é uma `string`.

## Exercício guiado

Crie um programa que mostre:

```text
Meu nome é Fernando
Estou aprendendo Python
```

Solução:

```python
print("Meu nome é Fernando")
print("Estou aprendendo Python")
```

## Tente sozinho

Mostre três mensagens:

1. seu nome;
2. seu curso;
3. por que quer aprender programação.

## Erros comuns

- esquecer aspas;
- escrever `Print` em vez de `print`;
- executar o terminal em outra pasta;
- salvar o arquivo sem `.py`.
