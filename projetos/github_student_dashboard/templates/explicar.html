Como o modo IA funciona

Sem OPENAI_API_KEY, nenhuma chamada externa é feita e o Dashboard usa uma explicação local transparente. Com a variável configurada, apenas o pacote de evidências do diagnóstico é enviado ao provedor para explicação pedagógica.

Nunca coloque chaves de API dentro do código, README, commits ou arquivos versionados.
