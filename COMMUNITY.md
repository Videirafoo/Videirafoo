# Comunidade Videirafoo

Este repositório é um espaço educacional aberto para estudantes e pessoas em início de carreira.

## Como participar

Você pode contribuir de quatro formas principais:

1. **Testando o GitHub Student Dashboard** e enviando feedback.
2. **Melhorando explicações** para torná-las mais claras para iniciantes.
3. **Corrigindo exemplos ou documentação** quando houver erro verificável.
4. **Enviando pequenas melhorias de código**, preferencialmente acompanhadas de teste.

## Feedback do Dashboard

Use o formulário oficial:

https://github.com/Videirafoo/Videirafoo/issues/new?template=dashboard-feedback.yml

Ao testar, informe principalmente:

- se conseguiu concluir a análise;
- o que foi mais útil;
- onde ficou confuso;
- qual melhoria deveria vir primeiro.

Não publique tokens, chaves de API, senhas ou dados privados.

## Primeira contribuição externa

A trajetória de contribuições open source externas está documentada em:

[`OPEN_SOURCE_START.md`](OPEN_SOURCE_START.md)

O primeiro exercício selecionado é uma issue introdutória de Flask criada especificamente para novos contribuidores.

## Princípios

- evidência antes de opinião;
- aprendizado antes de quantidade de commits;
- contribuições pequenas e revisáveis;
- nenhuma atividade artificial para aumentar métricas;
- respeito a licenças, autoria e regras de cada projeto externo.
