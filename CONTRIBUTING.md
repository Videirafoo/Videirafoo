# Como contribuir

Este espaço foi organizado para estudo e evolução prática em Engenharia de Software.

## Para estudantes

Você pode usar os exemplos como referência para:

- praticar exercícios;
- comparar soluções;
- propor melhorias;
- documentar aprendizados;
- transformar exercícios em pequenos sistemas.

## Sugestões de contribuição

1. corrigir explicações confusas;
2. melhorar exemplos;
3. adicionar casos de teste;
4. propor novos exercícios;
5. documentar erros comuns;
6. sugerir evolução de projetos.

## Antes de enviar mudanças

- mantenha o código simples e legível;
- explique a mudança;
- teste antes de publicar;
- não inclua `.venv`, senhas, tokens ou arquivos gerados;
- prefira commits pequenos e descritivos.

## Fluxo recomendado

```text
Issue → Branch → Alteração → Teste → Pull Request → Revisão
```

O objetivo é aprender práticas reais de desenvolvimento sem perder a clareza para quem está começando.
