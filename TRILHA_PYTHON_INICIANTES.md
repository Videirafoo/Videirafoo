# Trilha Python para Iniciantes

Esta trilha será a base do futuro repositório `python-para-iniciantes` do GitHub `Videirafoo`.

## Objetivo

Ensinar Python de forma progressiva, prática e acessível, levando a pessoa de zero conhecimento até pequenos sistemas organizados.

## Método

Cada módulo deve conter:

1. explicação simples;
2. exemplo mínimo;
3. exercício guiado;
4. exercício para tentar sozinho;
5. solução comentada;
6. erros comuns;
7. desafio extra;
8. como testar;
9. próximo passo;
10. fontes oficiais quando o assunto depender de versão.

## Módulo 0 — Preparação

- instalar Python;
- verificar `python --version`;
- instalar VS Code;
- executar o primeiro arquivo `.py`;
- entender terminal, arquivo e pasta;
- primeiro `print()`.

- `.gitignore`;

## Regra pedagógica

Não avançar apenas porque o código executou. Antes de passar para o próximo módulo, a pessoa deve conseguir explicar o que escreveu, modificar o exemplo e resolver um exercício parecido sem copiar.

## Revisão

Esta trilha deve ser revisada periodicamente para manter exemplos compatíveis com versões atuais do Python e com a documentação oficial.
